# LeafFlags

Java (Paper 1.21.11) port of your Skript file for player flags based on GeoIP country.

## Requirements
- [MiniPlaceholders](https://github.com/MiniPlaceholders/MiniPlaceholders) (required for placeholders like `<flags_flag>` and `<flags_code>`)
- PlaceholderAPI
- A geolocation expansion for PlaceholderAPI (just like the earlier Skript used `%%geolocation_countryCode%%`)

## Build

```bash
mvn clean package
